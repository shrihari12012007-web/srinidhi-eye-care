**Srinidhi Eye Care** is a modern healthcare web application designed for eye care clinics and hospitals to streamline patient appointment booking, specialty discovery, and ophthalmologist scheduling through an intuitive, accessible interface. Built with responsive client-side architecture and clean administrative layouts, the portal enables patients to explore clinical treatments and book diagnostic consultations with zero friction.

---

## :sparkles: Features

- :calendar: **Patient Appointment Scheduling:** Seamless appointment request workflow with specialty and time selection.
- :stethoscope: **Clinical Specialties:** Detailed overview of diagnostic services, cataract surgeries, retina care, and pediatric ophthalmology.
- :busts_in_silhouette: **Doctor Profiles & Timings:** Weekly consultation schedules for visiting surgeons and resident specialists.
- :iphone: **Responsive Interface:** Mobile-first design optimized for quick mobile access and desktop administrative oversight.

---

## :hammer_and_wrench: Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend / Admin:** Node.js, Express architecture
- **Deployment:** Render / Static Web Hosting
